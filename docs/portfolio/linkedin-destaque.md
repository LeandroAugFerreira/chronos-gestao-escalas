# Chronos 1.0 — conteúdo para Destaques no LinkedIn

**Link principal:** https://leandroaugferreira.github.io/chronos.html

**Tour de cenários (opcional):** https://leandroaugferreira.github.io/chronos-demo.html

**Título:** Chronos 1.0 | Gestão de jornadas e escalas — Python, React e OR-Tools

**Descrição:** Desenvolvi o Chronos para conectar pessoas, jornadas e decisões de planejamento. O projeto reúne uma interface com identidade própria, API em Python/FastAPI, simulação financeira e otimização de escalas com OR-Tools. A demonstração usa o Hospital Horizonte, com 350 colaboradores fictícios e 19 setores. Na página do projeto, você encontra o aplicativo Windows, documentação técnica, testes e uma visualização interativa do microensaio de escalas. Esse tour é estático, não executa o solver ou backend online e não representa implantação hospitalar.

**Imagem de apresentação:** `img/chronos-social.png`, no repositório do portfólio. É uma composição tipográfica da marca, sem simular uma captura da interface.

# Chronos 1.0 — conteúdo para Destaques no LinkedIn

**Link:** https://leandroaugferreira.github.io/chronos.html

**Título:** Chronos 1.0 | Gestão de jornadas e escalas — Python, React e OR-Tools

**Descrição:** Desenvolvi o Chronos para conectar pessoas, jornadas e decisões de planejamento. O projeto reúne uma interface com identidade própria, API em Python/FastAPI, simulação financeira e otimização de escalas com OR-Tools. A demonstração usa o Hospital Horizonte, com 350 colaboradores fictícios e 19 setores. Na página do projeto, você encontra o aplicativo para Windows, um roteiro rápido de avaliação e o manual online.

**Imagem de apresentação:** `img/chronos-social.png`, no repositório do portfólio. É uma composição tipográfica da marca, sem simular uma captura da interface.

Este arquivo prepara o conteúdo para o destaque. Não comprova a publicação no LinkedIn; o resultado precisa ser confirmado no perfil após a inclusão.
